# vue-monstr-game

This is a practice/showcase project that utilises Vue (using Vite), Pinia for state management, routing, Composition API and Options API. It's a functioning small game that encompasses many features. It uses Tailwind (and some custom css) for styling, it includes a Weather API for dynamic background changing, it has an e-commerce like shop (Potion shop) with occasional discounts. It has a calculator feature added to the shop (keyboard or mouse usage). It has a quest tab where you can set your own goals aswell (To-do list app). It features a Save/Load functionality which uses a small form, this way you can save and load your progress, also part of the form is connected to a note funcitonality, which appears as a dragable sticky not on large screen sizes. It utilises transitions, animations, has a character upgrade system with weaponry and armors. Also has a small battle log and some modals where it's a better fit.

In the future I might change the styling, there is some more optimization that could be done, i might go through the images to reduce their sizes, and there is an option menu in the plans where you can turn on/off sound effects and background music (the reason i haven't added it yet, is because it's basically just another store with Pinia and just going through the effects, it's just simply time consuming).

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
